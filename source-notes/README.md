# Source notes

Written reviews of outside material, in our own words. Nothing from an outside source
is adopted into a skill or the plays library without a review here first.

Raw transcripts, course files and vendor text are not stored in this repository.

## Format

Each review has: the source and the date it was reviewed; why it was reviewed; concepts
worth retaining; what not to import as doctrine; conflicts with other sources; and the
result, meaning where the retained material lands in the hub.

Volatile or weakly supported prescriptions are not thrown away. They are recorded as
claims and tested: specific tactics go into the plays library with a date, and
numerical rules become per-offer defaults that results can overturn.

## Adding a source

Drop the transcript or material where the reviewing agent can read it, outside this
repository. Write the review here. Add its plays to the plays library with the source
and date. Add any disagreement with existing sources to `conflicts.md`. Record the
source in `PROVENANCE.md`.
