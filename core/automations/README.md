# Automations (to build)

Scheduled routines. Each asks no questions, uses documented defaults, and stays inside
spend authority.

| Routine | Runs | Does |
|---|---|---|
| Daily watch | Daily | Reads each live offer; flags emergencies; changes nothing else |
| Session prep | Before each scheduled action session | Gathers evidence and drafts the batch of changes for approval |
| Weekly creative report | Weekly | Where spend went, what rose, new hits, hit rate, lessons |
| Monthly refresh | Monthly | Checks every dated reference for expiry; refreshes the plays library |
